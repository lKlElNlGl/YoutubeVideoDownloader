# YoutubeVideoDownloader для Android

Нативная версия проекта [medneem/YoutubeVideoDownloader](https://github.com/medneem/YoutubeVideoDownloader) (MIT). Интерфейс на русском языке. Без рекламы и подписок. Используется оригинальный значок из `assets/app.svg`.

## Скачать APK

**[Последний выпуск в GitHub Releases](https://github.com/lKlElNlGl/YoutubeVideoDownloader/releases/latest)**

Выберите APK `YoutubeVideoDownloader-vX.Y.Z-android.apk` в разделе Assets и установите напрямую, ZIP не нужен. Android 10+ (API 29). Сборка подписывается постоянным ключом, поэтому следующие релизы устанавливаются поверх предыдущих с сохранением данных.

**Важно для обновления с самого первого тестового APK 0.1.0:** он был подписан временным ключом GitHub Actions. Перейти на новую постоянную подпись поверх него нельзя. Единожды удалите ту первоначальную тестовую версию перед установкой первого подписанного релиза. В дальнейшем переустановка с потерей настроек не потребуется.

## Возможности

- Скачивание одного видео или аудио по HTTPS-ссылке YouTube; передача ссылки из меню «Поделиться» Android.
- Видео MP4 с ограничением качества: максимальное / 2160p / 1440p / 1080p / 720p / 480p / 360p.
- Аудио MP3, 192 кбит/с (FFmpeg).
- Имя файла берётся из исходного названия на YouTube (кириллица сохраняется), с ограничением чрезмерно длинных имён.
- Прогресс, ETA, отмена, просмотр скачанного файла, открытие папки загрузок через файловый менеджер.
- Очистка поля ссылки крестиком и сворачиваемый блок настроек.
- HTTP/HTTPS-прокси, импорт локального cookies.txt (формат Netscape).
- Проверка GitHub Releases при старте и по кнопке «Проверить обновления»; диалог скачивания/отмены, SHA-256 и подпись APK проверяются перед установкой. Новые версии не требуют аккаунта GitHub и токена.

Путь к файлам: `Downloads/YoutubeVideoDownloader/`. При невозможности прямого открытия папки приложение открывает системный интерфейс выбора файлов в указанной директории. Необходим установленный файловый менеджер Android.

## Подпись и автоматические релизы

GitHub Actions → **Android CI** выполняет тесты и проверяет debug-сборку, не публикуя ZIP. Workflow **Publish signed Android APK** создаёт релиз на каждый push в `main`, размещая APK и `SHA256SUMS` в GitHub Releases. Версия `0.2.<номер запуска>`, код версии монотонно увеличивается.

**Перед первой публикацией настройте два GitHub Actions secrets в этом репозитории:**
`ANDROID_SIGNING_KEY_PEM` и `ANDROID_SIGNING_CERT_PEM`.
Это долговременная пара приватного RSA-ключа в PEM и соответствующего самоподписанного сертификата X.509 в PEM. Пример локального создания с OpenSSL (файлы ключа никогда не добавлять в Git и никому не передавать):

```sh
printf '\n\n\n'
openssl req -x509 -newkey rsa:3072 -sha256 -days 36500 -nodes -keyout android-signing-key.pem -out android-signing-cert.pem -subj "/CN=YoutubeVideoDownloader Android/"
printf '\n\n\n'
```

Содержимое приватного PEM добавьте в Actions secret `ANDROID_SIGNING_KEY_PEM`; содержимое сертификата — в `ANDROID_SIGNING_CERT_PEM`. Сохраните ключ и сертификат в защищённом резервном месте: при их утрате невозможно подписывать совместимые обновления. Никаких секретов нет в публичном коде.

**Без секретов релиз не публикуется намеренно**: временно подписанный APK невозможно безопасно обновлять поверх предыдущего. После однократной настройки запустите workflow Publish signed Android APK вручную (workflow_dispatch) или сделайте push.

## Ограничения

Пока скачивание работает только при открытом приложении; полноценной фоновой службы, очереди и плейлистов нет. Само фактическое скачивание YouTube зависит от версии yt-dlp, QuickJS и ограничений YouTube, поэтому требуется проверка на телефоне. Загрузка APK отменяется с удалением временного файла. Обновления не устанавливаются без согласия пользователя и системного разрешения Android.

Встроены компоненты [youtubedl-android](https://github.com/yausername/youtubedl-android) и FFmpeg с собственными условиями лицензирования. Загружайте только материалы, на использование которых у вас есть права.
