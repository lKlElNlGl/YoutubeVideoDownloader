# YoutubeVideoDownloader — Android

Android-приложение на основе [medneem/YoutubeVideoDownloader](https://github.com/medneem/YoutubeVideoDownloader) (MIT), с нативным интерфейсом, локальной загрузкой через yt-dlp и FFmpeg. Бесплатно, без рекламы.

**[Скачать последнюю версию APK из GitHub Releases](https://github.com/lKlElNlGl/YoutubeVideoDownloader/releases/latest)**. APK находится в Assets **непосредственно**, не в ZIP. Минимальная версия Android — **10 (API 29)**.

## Возможности версии 0.3.1

- **Видео:** MP4 с выбором качества (максимальное, 2160p, 1440p, 1080p, 720p, 480p, 360p); при недоступности заданного разрешения выбирается поддерживаемое качество по правилам yt-dlp.
- **Аудио:** MP3, 192 кбит/с, извлечение FFmpeg.
- **Предпросмотр:** название, миниатюра, длительность и разрешения до начала загрузки.
- **Плейлисты YouTube:** распознавание ссылок с `list=`, получение списка роликов, выбор всех или отдельных видео, последовательное добавление в очередь, отображение общего числа завершённых заданий каждого плейлиста.
- **Очередь:** последовательная загрузка, сохранение заданий между запусками, прогресс, отмена, повтор, очистка завершённых; до 2000 активных заданий.
- **Фон:** Android foreground service, уведомление, работа при сворачивании приложения и выключенном экране в пределах разрешений и ограничений Android.
- **Место сохранения:** по умолчанию `Downloads/YoutubeVideoDownloader`; можно выбрать папку через Android Storage Access Framework и открыть её в файловом менеджере.
- **Названия файлов:** название исходного видео на YouTube, включая Unicode и кириллицу, с ограничением чрезмерно длинных имён.
- **Настройки:** HTTP(S)-прокси, выбор папки, отдельное обновление `yt-dlp`. Импорт cookies.txt удалён, прежний импортированный файл удаляется при миграции.
- **Оформление «Тёмный премиум»:** новый графитово-красный значок приложения, красные акценты, карточки, вкладки «Загрузка / Очередь / Настройки» и три темы строго в порядке **Светлая / Тёмная / Как в системе**. Настройки сгруппированы по назначению в постоянно видимые карточки; излишний раскрывающийся блок убран. Иконка заполняет холст без белых полей.
- **Обновления приложения как в SSH Button Next:** при открытии и по кнопке, периодическая проверка каждый час через WorkManager, звуковое уведомление при обнаружении новой версии (если Android разрешает уведомления), показ размера APK, прогресса и стадий проверки. Во время загрузки нажатия снаружи диалога и кнопка «Назад» не отменяют обновление; отмена только по кнопке. Проверяются SHA-256, packageName, версия и подпись перед установкой.

## Как использовать

1. Вставьте ссылку YouTube. Нажмите «Информация о видео» для предварительного просмотра.
2. Если ссылка содержит плейлист, появится список доступных видео. Выберите все или отдельные ролики.
3. Выберите формат и качество, затем нажмите «Добавить в очередь» либо «Скачать без очереди». Второе действие ставит задание первым среди ожидающих, не прерывая уже выполняющуюся загрузку. За статусом следите во вкладке «Очередь».
4. Выбор папки, прокси, тему и обновления можно найти во вкладке «Настройки». Кнопка «Вернуть папку по умолчанию» появляется только при выборе нестандартной папки.
5. Между вкладками можно переключаться нажатием или горизонтальными свайпами. Вертикальная прокрутка и работа с полями ввода сохраняются. После окончания загрузки нажмите «Открыть папку».

В плейлистах видео, удалённые или недоступные через `yt-dlp`, могут отсутствовать в списке. Весь доступный список выбирается по умолчанию; количество заданий не должно превышать 2000 одновременно.

## Изменения 0.3.1

- Исправлены белые поля по краям иконки.
- Более точное оформление по концепту «Тёмный премиум»: красные градиенты, тонкие рамки, отдельные карточки, радиус скругления кнопок уменьшен, межкнопочные интервалы увеличены.

- Переход между экранами свайпом влево/вправо (кроме жестов над полями ввода); текущий выбор и введённая ссылка сохраняются при смене темы.
- Удалены элементы cookies и соответствующие параметры yt-dlp.
- Кнопки папки: «Изменить папку» и «Вернуть папку по умолчанию». Вторая показывается только при нестандартной папке.

## Автоматическая сборка и выпуск

Workflow [Android CI](.github/workflows/android.yml) запускает `gradle --no-daemon testDebugUnitTest assembleDebug` при изменениях в main и feature-ветках. Workflow [Publish signed Android APK](.github/workflows/release.yml) публикует APK **только по явному триггеру**: правке `.github/RELEASE_TRIGGER.txt` в ветке main либо вручную (workflow_dispatch). Это исключает случайные релизы от каждого коммита.

Версия приложения и `versionCode` задаются **явно** в `app/build.gradle`; число запусков GitHub Actions больше не изменяет версию. Для каждого следующего релиза требуется увеличить обе версии. Подпись использует постоянные GitHub Actions secrets: `ANDROID_SIGNING_KEY_PEM` и `ANDROID_SIGNING_CERT_PEM`. Публикуются APK и SHA256SUMS, без ZIP.

**Переход со старой тестовой 0.1.0:** первый debug APK был подписан другим ключом; перед первым официальным релизом его нужно удалить. Все официальные релизы начиная с 0.2.6 используют один ключ и устанавливаются поверх друг друга.

## Важные ограничения

- Возможность скачивания зависит от текущих ограничений YouTube и работоспособности `yt-dlp`. После изменения защиты может потребоваться обновить движок.
- Фоновую службу Android 15+ может останавливать по лимиту времени или режиму энергосбережения. Принудительная остановка приложения всегда завершает работу; очередь восстанавливается при следующем запуске.
- Большие видео временно занимают место во внутреннем кеше приложения до переноса в папку назначения; необходимо достаточно свободного места на устройстве.
- Внешняя папка должна иметь право записи. При смене каталога уже поставленные в очередь задания сохраняют прежнюю папку.
- Автоматические проверки CI подтверждают компиляцию и юнит-тесты, но **не заменяют испытания реальных скачиваний и интерфейса на Android-устройстве**.
- Используйте загрузку только при наличии необходимых прав на материалы.

Сторонние компоненты: [youtubedl-android](https://github.com/yausername/youtubedl-android) 0.18.1, FFmpeg, yt-dlp и QuickJS. На их распространение действуют собственные условия лицензирования.
