# YoutubeVideoDownloader — Android

Нативная Android-версия проекта [medneem/YoutubeVideoDownloader](https://github.com/medneem/YoutubeVideoDownloader), MIT. Интерфейс на русском, без рекламы и подписок.

## Возможности первой версии

- Одно видео YouTube по HTTPS-ссылке.
- Видео MP4: максимальное, 2160p, 1440p, 1080p, 720p, 480p, 360p (в зависимости от доступных форматов).
- Аудио MP3 192 кбит/с, FFmpeg.
- Процент загрузки, ETA и отмена.
- HTTP/HTTPS-прокси, импорт cookies.txt в формате Netscape через системный выбор файла.
- Результат в системной папке Downloads через MediaStore, доступный другим приложениям.
- Ссылку можно передать через меню «Поделиться» на Android.

## Сборка

Откройте проект в Android Studio с JDK 17 или запустите GitHub Actions → Android APK. Pipeline использует Gradle 8.11.1, AGP 8.9.2 и Android SDK 35. Готовый APK доступен в Artifacts после **успешной** сборки. APK является debug-сборкой, не релизом из Google Play.

## Ограничения

Загрузка работает, пока открыт экран приложения; это пока не полноценный сервис для фоновой работы. При закрытии приложения операция может прерваться. Cookies импортируются в приватное хранилище приложения, не загружаются ни на какой сервер самого приложения. Используйте только собственные cookies и не публикуйте их.

Результат зависит от ограничений YouTube, версии yt-dlp и работоспособности встроенного QuickJS/EJS. Новая схема защиты YouTube может потребовать обновления библиотеки. Экземпляр APK требует проверки на реальном устройстве — CI проверяет сборку, но не скачивает YouTube.

Используются компоненты [youtubedl-android](https://github.com/yausername/youtubedl-android) (yt-dlp, FFmpeg, QuickJS и Python runtime); необходимо соблюдать лицензии сторонних компонентов. Скачивайте только материалы, на получение которых у вас есть права.
