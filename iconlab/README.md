# Icon Lab v0.5.7 — альфа-контур Clean C2 для нового мастер-рисунка

Обратная связь с Realme 8i / Android 12 по v0.5.6:
**A · Старый C2** — прозрачный фон работает;
**B · Новый 100%** — Realme добавляет белую подложку.

Две иконки в одном APK:
- **A · Старый C2** — абсолютно тот же PNG из v0.3.2.
- **B · Новый C2** — новый утверждённый мастер, подготовленный тем же
  способом 128×128, с восстановленной **только обработкой альфа-контура**
  старого Clean C2:
  1. `remove_external_matte` (старый округлый альфа-контур);
  2. `apply_cleanup(bottom_lift=2, alpha_cutoff=16)`;
  3. `apply_top_cleanup(top_lift=1.0, corner_radius=0)`;
  4. прежний `fit_canvas_subpixel` при масштабе 04b 1.05735.

**Внешний рисунок не перерисовывается.** RGB цвета утверждённой
кнопки, бликов, треугольника и стрелки неизменны **до финального
масштабирования**. Используются только изменения альфа-канала на
внешнем контуре; мастер-оригинал и его ресурс остаются неизменными.

Обычный PNG 192×192 `mipmap-xxxhdpi`, 2 `activity-alias`,
без adaptive-ресурсов, фоновых квадратов и ярлыков на рабочем столе.
Основное приложение не затронуто.
