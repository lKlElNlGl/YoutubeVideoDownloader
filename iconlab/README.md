# Icon Lab v0.5.3 — механизм иконки как в SSH Button Next

**Базовый рисунок не перерисовывался**. Используется прежний
`iconlab/assets/approved_master_display.webp` — подготовленная копия
утверждённого `YoutubeVideoDownloader_icon_master_clean.png`.

## Что в точности взято из SSH Button Next (master)

- `mipmap-anydpi-v26/*.xml` со ссылками на отдельные `background` и `foreground`.
- `drawable/*.xml` для `<inset>` вокруг переднего WebP-слоя.
- Все четыре inset = **9dp**, как в
  `ssh-button-next/app/src/main/res/drawable/ic_launcher_foreground.xml`.
- `drawable-nodpi` WebP-ресурсы **720×720 px** с альфа-каналом.
- На приложении явно указаны `android:icon` и `android:roundIcon`
  на одинаковый `mipmap` ресурс.
- Поведение кнопки остаётся старым: только включение восьми
  `activity-alias` в списке установленных приложений.

## Важное отличие от SSH

У SSH Button Next **фоновое изображение непрозрачное** (заливает весь
значок). Наш согласованный рисунок имеет **прозрачные углы**.
Чтобы их сохранить, `lab_background_art.webp` сделан полностью прозрачным,
а рисунок помещён в `lab_foreground_art_XX.webp` без изменения цветов,
силуэта и бликов. Искусственной чёрной подложки внутри APK нет.

**Ограничение устройства:** лаунчер может самостоятельно заполнить
прозрачные области адаптивной иконки чёрным или другим цветом — даже
если фон APK полностью прозрачный. Это нельзя гарантированно отменить
из стороннего приложения. Проверка на реальном устройстве обязательна.

В тесте восемь вариантов отличаются только масштабом переднего плана
(73% — 80% на 720px полотне). Подписи в списке приложений:
`01 · SSH 73%` — `08 · SSH 80%`.

Старый legacy-ресурс **128×128 → 192×192 mipmap-xxxhdpi** остаётся
как fallback для других версий Android. Основное
YoutubeVideoDownloader не затрагивается.

Для теста удалить Icon Lab v0.5.2, поставить v0.5.3 и нажать
**«Показать 8 вариантов»**. Системные ярлыки на рабочий стол не создаются.
