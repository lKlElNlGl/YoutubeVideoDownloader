# Icon Lab v0.5.2 — прозрачная иконка для лаунчера Android

Используется **тот же утверждённый рисунок** `YoutubeVideoDownloader_icon_master_clean.png`.
Мастер не изменяется, новые цвета и подложки не добавляются.

## Почему Icon Lab v0.5.1 показывал белый квадрат

На устройстве системный лаунчер обрамляет старый тип значка (legacy PNG)
белой маской и уменьшает рисунок внутри. Этот квадрат **не был частью PNG**.
Увеличение legacy PNG с 109% до 115% не меняет поведения лаунчера.

## Изменение v0.5.2

- Исходный механизм включения 8 `activity-alias` **сохранён**: кнопка
  `Показать 8 вариантов` показывает значки **только в списке приложений**.
  Никаких `ShortcutManager` и запросов закрепления на рабочем столе.
- Для Android 8+ каждому варианту добавлен системный **adaptive-icon** ресурс
  `mipmap-anydpi-v26/lab_size_XX.xml`. Background прозрачный,
  foreground — уменьшенная, не перекрашенная копия утверждённой иконки.
- В foreground сохранена центральная безопасная зона Android;
  8 вариантов отличаются только размером исходного рисунка.
- Старый проверенный `128×128 → 192×192` legacy `mipmap-xxxhdpi` PNG
  и масштаб 04b **оставлены как fallback**, без изменений алгоритма.
- Основной YoutubeVideoDownloader не затронут.

**Важно:** Некоторые OEM-лаунчеры игнорируют прозрачность адаптивной
подложки. Это проверяется на реальном телефоне, поэтому полное отсутствие
белой маски нельзя гарантировать без теста устройства.

## Установка

Удалить предыдущий Icon Lab v0.5.1 (очистит устаревшие ярлыки и кэш),
установить новый APK, открыть и нажать «Показать 8 вариантов».
После этого проверить, отображаются ли значки 01–08 без белой плитки.
