# Icon Lab v0.5.8 — восстановлена проверенная маска значка

После v0.5.7 на Realme 8i (Android 12) старый A без подложки, новый B
с белым скруглённым квадратом. Проведено измерение **реальных
PNG в GitHub Actions**: площадь альфа >128 составила **90.4%** у
старого A и **88.5%** у нового B. Исторические маски различаются, хотя
предыдущая обработка Clean C2 уже применялась к новому рисунку.

На Android Launcher3 обычные иконки с неподходящим контуром
могут автоматически оборачиваться в adaptive icon c белым фоном.
Следующий тест целенаправленно проверяет эту ветку поведения.

**Значки:**
- `_A · Старый C2` — точный PNG успешной Icon Lab v0.3.2.
- `_B · Маска A` — RGB нового утверждённого рисунка после
  подготовки C2 **бит-в-бит остаётся прежним**, но
  **альфа-канал готового PNG 192×192 копируется пиксель-в-пиксель**
  из рабочего A, включая наружные края и прозрачные углы.

Используются только legacy PNG в `mipmap-xxxhdpi` и
`activity-alias`. **Никаких адаптивных слоёв или заливки.**
Утверждённый мастер-оригинал и основное приложение не изменяются.
