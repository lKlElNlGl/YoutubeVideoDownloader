# Icon Lab v0.5.11 — две пользовательские иконки без изменений

Используются **оригиналы двух файлов, которые пользователь прислал**,
а не результат предыдущей автоматической обрезки или масок.

- `_A_192px`: **77.png**, 192×189 px, исходный PNG без изменений
- `_B_Большая`: **555.png**, 1035×1019 px, исходный PNG без изменений

Файлы вставлены непосредственно как бинарные Android-ресурсы
`drawable-nodpi/lab_user_a_192.png` и
`drawable-nodpi/lab_user_b_large.png`. Это важно: в APK хранится
вторая картинка исходного большого размера, а не уменьшенная до 192px.

Иконки включаются кнопкой **«Показать 2 значка»** в меню приложений,
через две `activity-alias`. Программа **не создаёт ярлыки на рабочем
столе автоматически**.

Ни перерисовки, ни обработки альфа-маски, ни фоновых слоёв,
ни адаптивных значков. В приложение не попадают автоматические
генерируемые иконки из предыдущих диагностических версий.

CI проверяет SHA-256 обоих оригиналов, их размеры, альфа-канал,
настройки манифеста и наличие обоих ресурсов в APK.

Главное приложение YoutubeVideoDownloader не меняется.
