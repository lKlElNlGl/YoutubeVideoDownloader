# Icon Lab v0.5.1 — старый рабочий способ отображения значков

**База не меняется:** `YoutubeVideoDownloader_icon_master_clean.png`,
1254×1254 RGBA, утверждённый пользователем. Тестовый источник
`iconlab/assets/approved_master_display.webp` — уменьшенная копия
мастер-оригинала, не художественная переработка.

## Тот же метод, что в рабочем Icon Lab v0.2.1/v0.3.2

- Исходный размер для рендеринга: **128×128 px**.
- Ресурс Android: **192×192 px** как legacy PNG в `mipmap-xxxhdpi`.
- Масштаб № 01 — точный прежний **04b (1.06 × 0.9975)**.
- Варианты № 02–08 — масштаб 109, 110, 111, 112, 113, 114, 115%.
- Только `activity-alias`; без adaptive icon, `ShortcutManager`, системных
  pinned shortcuts и белых подложек в наших изображениях.
- Рисунок, цвета и прозрачность исходного мастер-файла остаются неизменны.
  Допускается только ресайз и центрирование на прозрачном холсте.

В приложении нажать **«Показать 8 вариантов»** — все варианты
появятся в списке приложений Android. Вручную перетащить выбранный
значок на рабочий стол, если нужно.

Ранее созданные системные ярлыки v0.5.0 Android не удаляет автоматически:
удалить их с рабочего стола вручную. При конфликтах подписи можно удалить
старый Icon Lab и установить тестовый APK заново.

Основной YoutubeVideoDownloader не изменяется.
