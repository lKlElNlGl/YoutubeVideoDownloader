# Icon Lab v0.5.9 — чистый сглаженный контур

Проверено пользователем на Realme 8i: v0.5.8 позволила убрать белый фон
при переносе внешней маски рабочего старого Clean C2 на новый рисунок,
но на краю новой кнопки появилась неровная/грязная кайма.

## Два значка
- \`_A_Старый C2\` — пиксель-в-пиксель прежний работающий
  \`lab_clean_c2.png\` из Icon Lab v0.3.2 (неизменённый контроль).
- \`_B_Сглаженная маска\` — новый утверждённый мастер, подготовленный
  прежним способом, с восстановленным силуэтом работающего старого
  значка и улучшенной обработкой края.

## Коррекция B
1. Берём старую альфа-маску A, порог ≥128 для чистого силуэта.
2. Увеличиваем до **1536×1536 (8x)**, сглаживаем и уменьшаем до 192×192
   с LANCZOS.
3. Для участков по краю, на которых новая маска открывает прежние
   полностью прозрачные пиксели RGB, переносим цвета **ближайших
   непрозрачных пикселей чёрного корпуса новой иконки**. Тем самым
   устраняем случайные цветные/серые помехи, вызванные грубым
   переносом альфа-канала.
4. Пиксели новой иконки с исходной альфой ≥200 остаются с исходными
   RGB **пиксель-в-пиксель**; утверждённый мастер-файл не меняется.

Обычный PNG 192×192 \`mipmap-xxxhdpi\`, два \`activity-alias\`,
без adaptive-ресурсов/заливок/автоярлыков на рабочем столе.
Основной YoutubeVideoDownloader не затрагивается.

Физический результат на Realme проверяется отдельным скриншотом;
прохождение CI подтверждает цифровые свойства PNG, но не внешний вид
лаунчера конкретного телефона.
