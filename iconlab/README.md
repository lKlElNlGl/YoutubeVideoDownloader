# Icon Lab v0.5.4 — возврат настоящего способа v0.3.2

**Подтверждено пользователем:** на Realme 8i (Android 12) варианты Icon Lab
v0.3.0/v0.3.2 отображались с прозрачными углами. Следовательно,
утверждение о невозможности такого отображения было ошибочным.

В этом выпуске полностью возвращаем механизм **legacy PNG**:
- `mipmap-xxxhdpi`, 192×192, без `mipmap-anydpi-v26`.
- Прежняя функция `fit_canvas_subpixel` и масштаб эталона 04b 1.05735.
- Обычные `activity-alias` и кнопка «Показать 8 вариантов», никаких ярлыков.
- Главный значок приложения `@drawable/lab_app_icon`, без `roundIcon`.

**Отличие нового мастер-оригинала:** он содержит больше прозрачных полей
(тело ~83% холста), чем подготовленный старым скриптом ресурс. При
слепом уменьшении в v0.5.1 рисунок занимал слишком мало места и Realme
добавлял белую плитку. Теперь **обрезаются только пустые поля вне
кнопки**, а изображение равномерно вписывается в прежнюю геометрию
128×128 с отступом 4px; RGB кнопки, блики и форма не перерисовываются.

Варианты: 01 — прежний 04b; 02–08 — масштабы 100,101,102,103,104,
105,106%. Цель — подтвердить правильный тип ресурса и размер на Realme
без очередного изменения исходного мастер-файла.

APK выпускается отдельно от основного YoutubeVideoDownloader. Из APK
полностью исключены адаптивные фоновые ресурсы предыдущих тестов.
