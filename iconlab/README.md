# Icon Lab v0.5.5 — 11 вариантов одной иконки

По согласованию: **от 96% до 106% включительно, шаг 1%**. Все
варианты создаются из одной утверждённой иконки
`YoutubeVideoDownloader_icon_master_clean.png` через подготовленный
`iconlab/assets/approved_master_display.webp`, без перерисовки.

Иконки **01–11** имеют соответственно масштабы
96, 97, 98, 99, 100, 101, 102, 103, 104, 105 и 106%.

**Алгоритм подготовки не изменён относительно v0.5.4**:
- исходное изображение пропорционально вписывается в старую
  128×128 схему с 4 px прозрачного отступа (пустые поля вне рисунка
  удаляются только для подготовки);
- одна и та же полученная база для всех 11 вариантов;
- `fit_canvas_subpixel` масштабирует базу целиком на прозрачном
  холсте 192×192, с 8-кратным сглаживанием;
- legacy PNG в `mipmap-xxxhdpi`, **без адаптивных фоновых слоёв**;
- `activity-alias` (11 штук), кнопка **«Показать 11 вариантов»**
  выводит их только в списке приложений, не на рабочем столе.

Сам рисунок (корпус, красная кнопка, треугольник, стрелка, их
пропорции и цвета) не редактируется. Главный YoutubeVideoDownloader
тоже не меняется.

**Важно:** новое изменение масштаба не гарантирует исчезновение
белой подложки, если её добавляет Realme Launcher.
